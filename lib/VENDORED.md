# Vendored Larzscript libraries

`json/` and `toml/` are copied verbatim from the Larzscript package
monorepo (github.com/larz-scripter/larzscript-packages) so this repo runs
straight after `git clone` with no `larzscript pkg install` step.

On a real LarzOS system these ship in the `larzscript` stdlib package and
this directory is not used.
